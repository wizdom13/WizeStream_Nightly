# NewPipe Material Nightly

This repository distributes automated prerelease builds of [NewPipe Material](https://github.com/wizdom13/NewPipe_Material).

## Warning

Nightly builds are generated from the latest tested commit on the `pipe` branch. They may contain unfinished changes or regressions and are intended for testing only.

Nightly builds use the application ID `org.wisso.newpipematerial.nightly`, so they can be installed alongside the stable NewPipe Material application.

## Downloads

Download the newest APK from the repository's **Releases** page. Each release includes:

- a signed nightly APK;
- a SHA-256 checksum;
- the exact NewPipe Material source commit;
- the exact Pipe
